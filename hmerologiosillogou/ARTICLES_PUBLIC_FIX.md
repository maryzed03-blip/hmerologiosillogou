# Public articles visibility fix

Διόρθωση συμβατότητας για παλαιότερα άρθρα που είχαν `approval_status: approved`
αλλά δεν είχαν αποθηκευμένο το νεότερο πεδίο `is_public`.

Με αυτή την έκδοση:
- εγκεκριμένα παλαιότερα άρθρα εμφανίζονται στη δημόσια `/articles`,
- νέα άρθρα διαχειριστή συνεχίζουν να δημοσιεύονται άμεσα,
- άρθρα μελών συνεχίζουν να απαιτούν έγκριση από διαχειριστή,
- ρητά ιδιωτικό άρθρο (`is_public: false`) παραμένει κρυφό.
