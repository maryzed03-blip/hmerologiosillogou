# SEPSYG v1.5

## Διακριτικό +
Στη δημόσια σελίδα υπάρχει μικρό + επάνω δεξιά.
- MANAGE_CODE / 1111 => member: διαχείριση δράσεων.
- ADMIN_CODE / 2222 => admin: διαχείριση + προσωπικά στοιχεία / λίστες συμμετοχών.

Η πρόσβαση εξακολουθεί να ελέγχεται server-side από /api/verify-manage-code.

## Αυτόματο Προσεχώς / Ολοκληρώθηκε
Η δημόσια σελίδα και η διαχείριση δεν βασίζονται πλέον μόνο στο αποθηκευμένο status.
Υπολογίζουν αυτόματα:
- παλαιότερη ημερομηνία => Ολοκληρώθηκε
- μελλοντική ημερομηνία => Προσεχώς
- σημερινή ημερομηνία + εύρος ώρας (π.χ. 19:00–21:00) => Ολοκληρώθηκε μετά την ώρα λήξης
Χρησιμοποιείται ζώνη ώρας Europe/Athens.
