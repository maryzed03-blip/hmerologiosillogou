# Carrd — Articles only embed

Νέα δημόσια διαδρομή:

`/articles-embed`

Η διαδρομή εμφανίζει μόνο τις κάρτες των δημοσιευμένων άρθρων, χωρίς logo, τίτλο ή εισαγωγικό κείμενο.
Η κανονική `/articles` παραμένει όπως ήταν.

Για Carrd χρησιμοποίησε το αρχείο `SEPSYG_CARRD_ARTICLES_ONLY_EMBED.txt` που δόθηκε ξεχωριστά.
